# Финальное тестовое: обёртка над Keitaro

> Вводная из сообщения заказчика. Полное ТЗ — в Notion:
> https://app.notion.com/p/mnovikov/Adrobot-2b01eb78a7bb80a1b188c3a4a1cad55e
> (выгрузка — этап 1 плана, см. `.plan/PLAN.md`).

Это задание познакомит тебя с одной из систем, с которыми мы работаем каждый день. Срок — 5 дней.

Keitaro — рекламный трекер: по нему мы смотрим, насколько прибыльны объявления. Технически это
конструктор ссылок: он перенаправляет пользователей по настроенным правилам и показывает
статистику переходов.

Задача из двух частей:

1. **Создаватор кампаний.** Принимает название кампании, гео-код страны и ID оффера в Keitaro.
   Создаёт кампанию с двумя потоками: первый ловит всех из указанной страны и отправляет на
   Google, второй отправляет на выбранный оффер. У кампании должны быть настроены домен, группа
   и источник — всё это есть в API.
2. **Редактор существующей кампании.** Умеет добавлять и удалять офферы. У нас такой редактор
   уже есть, видео с ним — в полном ТЗ. Интерфейс на твой вкус, главное — рабочие кнопки и
   верные цифры.

**Стек:** FastAPI + SQLAlchemy, фронт любой — хоть React, хоть HTML с jQuery. Cursor, Windsurf и
другие ИИ-агенты категорически приветствуются.

**Как сдавать:** ссылка на GitHub с понятным README по миграциям и запуску.
